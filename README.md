# TeeTime Booking Pro

Manages golf tee-time availability, customer bookings and payments in WordPress.

## Installation

1. Place this directory at `wp-content/plugins/teetime-booking-pro/`.
2. Activate WooCommerce, then activate **TeeTime Booking Pro**.

## Usage

Publish `[ttbp_booking_form]` for reservations and `[tee_time_calendar]` for the calendar. Use `[ttbp_my_bookings]` for customer bookings and `[ttbp_starter_sheet]` for the starter sheet. Configure course and payment settings before taking reservations.
